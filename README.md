# 🎯 CodSoft Python Projects

A curated collection of beginner-friendly Python applications built as part of the **CodSoft Internship**.  
These projects demonstrate the use of **Tkinter**, **file handling**, **Python logic**, and **GUI development**.

---

## 🧩 Projects Included

### 1. 📦 Box-Type Calculator (`calculator_codesoft.py`)
A GUI calculator with a bold box-style layout. Supports basic arithmetic operations with a modern theme.

> ✔️ Features: Grid layout, real-time evaluation, error handling  
> 🛠 Built using: `Tkinter`, `eval`, custom themes  
> 🎨 GUI: Dark button style + styled display  

---

### 2. 📇 Contact Book (`codesoft_contact_book.py`)
A simple **contact management system** to store and retrieve contact information (name, phone, email).

> ✔️ Features: Add, search, delete contacts  
> 📁 Data Storage: Text file or in-memory (depends on your version)  
> 🛠 Built using: `Tkinter`, `file handling`  

---

### 3. 🔐 Password Generator (`python_codesoft_gen_pwd.py`)
An interactive GUI app to generate strong random passwords based on user preferences.

> ✔️ Features: Select length, include symbols/digits  
> 🔐 Output: Secure and randomized passwords  
> 🛠 Built using: `Tkinter`, `random`, `string`  

---

### 4. ✅ To-Do List App (`python_todo_Codsoft.py`)
A simple to-do list GUI that allows users to add and remove tasks.

> ✔️ Features: Add/delete tasks, display list  
> 📁 Data Persistence: (Optional – you can enhance with file save)  
> 🛠 Built using: `Tkinter`, `listbox`  

---

### 5. ✊ Rock-Paper-Scissors Game (`rock_paper-scissor.py`)
A fun CLI-based game to play Rock-Paper-Scissors against the computer.

> ✔️ Features: Random moves, win/lose/draw logic  
> 🤖 Built using: `random`, `input/output`  
> 🎮 Interface: Command Line
